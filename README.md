# Онлайн-зоомагазин "Лапаград"

## Предметная область
Данный проект охватывает сферу **электронной коммерции (E-commerce) в нише Pet Care** (товары для животных). База данных спроектирована для автоматизации процессов розничной продажи домашних питомцев, кормов, клеток, аксессуаров и других сопутствующих товаров.

## Какую проблему решает проект?
Учет в зоомагазинах осложнен тем, что товары сильно отличаются друг от друга: живые питомцы требуют особого контроля, а корма и клетки имеют разные категории и характеристики, поэтому нужно правильно и удобно разделить живой товар от аксессуаров. Этот проект решает **проблему централизованного и безопасного управления данными зоомагазина**.

А еще проект решает проблему хаоса в учете продаж и структуры чеков, с которой сталкиваются магазины при ручном ведении дел. Система позволяет автоматизировать контроль специфичного ассортимента, безопасно хранить контактные данные клиентов для маркетинга, а также детально фиксировать состав каждого заказа, исключая потерю информации о покупках и остатках товаров.
